# 💻 系統平台的組成架構－硬體｜互動學習網

本專案為高職《數位科技概論》第三章「系統平台的組成架構－硬體」所設計之互動視覺化學習網站，支援 **RWD 響應式網頁** 與 **PWA 離線安裝**，免後端伺服器即可部署於 GitHub Pages。

## ✨ 核心功能亮點
1. **教學與學習指引**：完整提供教師四節課教學建議與學生四步驟自學指南。
2. **四大互動視覺化教材**：
   - 電腦硬體五大單元互動流向圖（SVG 互動）
   - CPU 機器週期（擷取／解碼／執行／儲存）動態模擬器
   - 記憶體階層金字塔與 SSD / HDD 規格比較
   - 常見連接埠（USB-C、HDMI、DisplayPort、Thunderbolt 4、RJ-45、M.2）速查
3. **進階與延伸學習**：涵蓋企業級硬碟（RAID / SAS / NAS）、環保認證（RoHS / EPEAT）、3D 印表機與單晶片電腦（Raspberry Pi / Arduino / micro:bit）。
4. **反覆演練與單元測驗**：收錄統測歷屆試題與課本精選習題，提供即時詳解與自動計分。
5. **學習歷程紀錄與下載**：自動追蹤瀏覽、演練與測驗成績，支援匯出 `.txt` 與 `.json` 報告。
6. **國語／台灣台語雙語切換**：全站介面支援一鍵切換國語與台灣台語文字。
7. **七大顯示與操作設定**：全螢幕、音效開關、裝置模擬（自動／手機／平板／電腦）、版面方向（自動／直式／橫式）、語言、字體大小（縮小／標準／放大）、色系（跟隨系統／亮色／暗色）。
